## 缺口判定规则

- 如果某能力可以用主资料包中的 IDAPython / headless / MCP 官方页面证明，就按项目代码和测试继续审计。
- 如果某能力只能用 GUI 教程、菜单操作、弹窗流程或 C++ SDK 证明，默认不算当前 Python 项目的可交付能力。
- 如果官方资料显示 headless 场景不支持某能力，工具必须返回 `unsupported` 和机器可执行诊断，不得把 GUI 操作写成默认修复路径。
