IL2CPP 始终作为 Native workspace 的注解层。

## 固定限制

- Python 仅支持 3.13。
- 静态查询必须显式携带 `workspace_id` 与 `revision`。
- `program.search` 的文本域是 `function`、`name`、`string`；显式空 `text_query`
  确定性枚举所选文本域，`bytes_query` 只用于独立的 `bytes` 域。
- `workspace.export` 当前只导出 IDB，并返回 chunk index artifact。
- 分页默认 50、最大 200；图默认 200 节点、硬上限 1000。
- 单次 debugger 内存读取最大 64 KiB。
- dataflow 的 MUST 边只表示目标 use 的全路径唯一 reaching def，不表示控制流必经；
  不宣称跨函数或全程序 taint。
- 动态操作不以“请求进入队列”作为成功。
- Job Object 不是执行沙箱。
- Expert 是开放世界 IDAPython；即使在 disposable staging worker 中，服务也不能阻止
  文件、网络或子进程访问。

## `1.0.0` 外部门禁

截至 2026-07-25，MCP `2026-07-28` 仍是 release candidate，Python MCP SDK v2
仍是预发布版本。正式规范发布、`mcp==2.0.0` 稳定版可用并完成 current-only 差异审计
之前，不得发布 `ida-re-mcp 1.0.0`。

验收环境中的 Inspector `0.21.2` 发送的协议版本不等于 `2026-07-28`，会被严格入口以
`-32602` 拒绝。可使用正式 current 协议的 Inspector 及其正向验收也是外部门禁；不得
用额外协议分支绕过。
