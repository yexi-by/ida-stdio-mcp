## 固定边界

- Python 固定为 3.13。
- Native 输入只接受表中经过硬门禁的直接镜像；不接受 ELF32、大端 ELF、ET_REL、
  扩展 program-header 数量、Mach-O、脚本或压缩包装器。
- 服务只广告 tools 与不可变 resources；不广告 Tasks。
- 静态查询必须显式携带 `workspace_id` 与 `revision`。
- 分页默认 50、最大 200；图默认 200 节点、硬上限 1000。
- 单次 debugger 内存读取最大 64 KiB。
- dataflow 只承诺函数内、microcode 支持的 MAY/MUST def-use 与有界 slice；未知调用和
  别名内存形成 `unknown` barrier。
- `workspace.export` 只导出 IDB。
- 动态操作不以“请求进入队列”作为成功，只有观察到对应事件或允许的运行状态才完成。
- Job Object 不是执行沙箱。
- Expert 是开放世界 IDAPython。

当前契约不包含进程内存写入、远程调试、普通 .NET/Mono workspace、通用调用捕获、
伪 timeline 或外部分析器执行链。IL2CPP 始终是 Native workspace 的原生注解层。

## 发布门禁

`1.0.0` 必须同时满足：

1. `uv lock/sync`、Ruff、basedpyright strict、pytest 全通过；
2. wheel 无源码构建、隔离安装和标准 stdio smoke 通过；
3. 官方 Python SDK client、Codex 与 OpenCode 的真实 MCP 握手和调用通过；
4. 自有 fixture 双目录构建结果一致；
5. 受许可 IDA 9.3+ 的静态、mutation、IL2CPP 与 Expert 门禁通过；
6. Windows 本机 x64 debugger 门禁通过；
7. 当前工作树只包含当前产品身份、当前严格配置和官方 SDK 协议边界，不包含运行产物。
