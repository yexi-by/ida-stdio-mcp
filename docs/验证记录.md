## Headless IDA Runtime

未设置 `IDADIR` 时，`runtime_health` 返回：

- `status`: `misconfigured`
- 原因：`idapro` 包存在，但 `idalib.dll` 无法加载。
- 修复：设置 `IDADIR` 指向有效 IDA 9.3+ 安装目录。

设置 `IDADIR=<IDA_INSTALL_DIR>` 后，runtime probe 通过：

- `status`: `available`
- IDA 版本：`9.3.260213`
- 来源：`IDADIR`
