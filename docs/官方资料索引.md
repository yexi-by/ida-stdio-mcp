# 官方资料索引

本项目的协议、SDK、IDA 与 Unity 设计只引用下列权威资料。实现和文档发生歧义时，以
锁定版本的规范、SDK API 和目标产品文档为准。

## Model Context Protocol

- [MCP 2025-11-25 稳定规范](https://modelcontextprotocol.io/specification/2025-11-25)
- [生命周期与能力协商](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle)
- [stdio 与 Streamable HTTP transports](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)
- [Tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)
- [Resources](https://modelcontextprotocol.io/specification/2025-11-25/server/resources)
- [Python SDK v1.28.0](https://github.com/modelcontextprotocol/python-sdk/tree/v1.28.0)
- [MCP Inspector](https://github.com/modelcontextprotocol/inspector)
- [Tasks 扩展（Experimental）](https://github.com/modelcontextprotocol/ext-tasks)

服务使用官方 Python SDK v1.28.0 的低层 `Server` 与 stdio transport，遵循标准初始化、
能力协商和关闭生命周期。服务只注册 tools 与不可变 resources；Tasks 仍是实验扩展，
不进入本产品的工具目录或能力声明。

## IDA Pro 与 IDAPython

- [IDAPython 9.3 API](https://python.docs.hex-rays.com/)
- [IDA debugger API](https://python.docs.hex-rays.com/ida_dbg/index.html)
- [Hex-Rays decompiler API](https://python.docs.hex-rays.com/ida_hexrays/index.html)
- [IDA 命令行参数](https://docs.hex-rays.com/user-guide/configuration/command-line-switches)

Supervisor 不导入 IDA。所有 IDA API 调用只在独立 worker 的 owner 线程执行；静态分析、
冷验证和动态调试必须使用受许可的 IDA Pro 9.3+ headless 环境。

## Unity IL2CPP

- [Unity IL2CPP 概览](https://docs.unity.cn/Manual/IL2CPP.html)
- [调试 IL2CPP 生成的 C++](https://docs.unity.cn/Manual/uwp-debug-generated-cpp.html)

IL2CPP 在本项目中只是 Native workspace 上的类型、符号和 provenance 注解层。服务不
建立 managed workspace，也不执行外部分析器；managed signature 只用于身份和展示，
只有明确的 native signature 可以写入 IDA。
