截至核对日期，`2026-07-28` 仍是 release candidate，正式规范计划于 2026-07-28
发布。Python SDK v2 仍是预发布版本，官方明确不建议用于生产，稳定版目标日期为
2026-07-27。Tasks 仓库仍标记为 Experimental。

因此当前服务：

- 只接受 `2026-07-28`；
- 只使用精确锁定的 v2 beta 类型和低层处理边界；
- 不广告 Tasks；
- 不标记 `1.0.0`，直到正式规范与稳定 SDK 完成差异审计和全部门禁。

当前验收环境固定的 Inspector `0.21.2` 发送的协议版本不等于 `2026-07-28`，因此严格
stdio 入口会以 `-32602` 拒绝该请求。Inspector 官方发布说明同时指出，与
`2026-07-28` 规范配套的新 Inspector 将使用新的代码库。项目不增加其他协议分支；
可执行 current-only 正向验收的 Inspector 是发布外部门禁。
